# antislop audit 001 (2026-11-23)

**Scope:** the SBOMVert UI on `main`: the full app, the static build's pages that are on `main`, and `DESIGN.md`. Rules from antislop 3.2.32 (core, `antislop-ui`, `antislop-human`).

**Method:**
- Read the source.
- Computed contrast ratios with the skill's `contrast-check.py`, using the token values in `src/app/globals.css`.
- Not run in a browser for this audit.

**Priority** follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

**What already holds:**
- Tokens are enforced by a lint rule.
- A working light/dark toggle exists.
- No fake stats, testimonials or claims.
- No gradients, glass or glow.
- Focus rings use `ring-ring`.
- Inline form errors in `SbomUploadForm`.
- Empty states on the image list.
